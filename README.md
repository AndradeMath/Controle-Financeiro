# Controle Financeiro

Aplicação desenvolvida em React para gerenciamento financeiro pessoal.

## Funcionalidades

- Dashboard financeiro
- Controle de receitas e despesas
- Categorias personalizadas
- Gráficos de análise
- Controle de orçamento
- Controle de cartões
- Metas de economia
- Filtros por período
- Persistência com LocalStorage

## Tecnologias

- React
- Vite
- React Router
- Recharts
- JavaScript
